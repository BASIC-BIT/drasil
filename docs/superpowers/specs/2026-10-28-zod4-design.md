# Patched Zod 4 migration

Issue: #275. The user authorized the coordinated migration and continuous iteration through a merge-ready PR, without further design approval pauses.

## Intent and scope

Remove GHSA-mrhx-c7xc-m3w5 from the installed dependency graph by moving contracts, application, bot and web to Zod 4.6.7 or newer patched Zod 4. Upgrade OpenAI to a maintained Zod 4 compatible release. Replace zod-to-json-schema with native Zod conversion. Preserve moderation behavior, persisted command shapes, defaults, preprocessing aliases and validation strictness. No database migration or model/prompt changes.

## Approach

Use one coordinated upgrade. A staged upgrade retains vulnerable Zod 3 and duplicates schema boundaries. A compatibility shim also retains the vulnerable implementation. Neither satisfies the security goal.

Keep the MCP Standard Schema adapter where it expresses input-only advertising and broad output, but generate JSON Schema with Zod 4 in input mode. Preserve permissive advertisement of preprocessing inputs and strict runtime canonical validation. Honor SDK JSON Schema targets. Update Zod type signatures, explicit record keys and type narrowing where Zod 4 requires it.

## Verification

Run npm audit and inspect the installed production graph for Zod 3 and zod-to-json-schema. Run repository CI, including browser, database and production-package gates. Leave visual baselines unchanged. Resolve review feedback and leave the PR unmerged.
