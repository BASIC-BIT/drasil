## Task 6: compromised-account quarantine

Discord previews and modal submissions call `QuarantineActions`; dashboard submissions encode the same two persisted request variants and the worker dispatches them through the same actions. Preview and execution require fresh moderation authority (owner, Administrator, Manage Guild, or Moderate Members) and fresh fail-closed quarantine settings. Execution requires a reason and a server-resolved preview bound to actor, guild, case, target, expiry and live containment state. Discord keeps the shipped 20-character fingerprint in custom IDs and a runtime-owned full binding; web keeps the completed preview request ID and ten-minute expiry. Discord acknowledges before preview reads and defers execution replies.
