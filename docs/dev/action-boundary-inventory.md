# Action boundary caller inventory

The shared action boundary is tracked in issue #89 and the [approved design](../superpowers/specs/2026-10-19-shared-action-boundary-design.md). This checklist begins with every coverage-ledger entry. Pending families must expand their caller groups into exact symbols, policies, confirmations, delivery, shared owners, and regression tests when migrated. A pending row is not migration evidence.

Fresh report-review authority is loaded through the existing web authority adapter. Authority facts must match both actor and guild; departed actors and internal system actors cannot review submitted reports. Configured responder roles retain the report-intake staff rule, while the web entry gate still requires Manage Server. Review commands cannot supply actor, source, permissions or internal attempt tokens. Closure keeps `closed_by`, `closed_action`, `closed_at`, `closed_surface`, existing busy/already-handled outcomes and best-effort attention cleanup. Case submission keeps the target/report/detection binding, `requested_surface`, `report_intake_id`, and `web:report-open-case:<guild>:<report>:<detection>` key. A queued or processing receipt remains `queued`, while a completed request is `already_handled`.

The baseline's `ReportInteractionHandler admin-review path` label was incorrect. That handler has no shipped submitted-report review status change or submitted-report case-opening action. Its confirmed Close Report path invokes `ReportIntakeService.closeIntakeForThread`, archives the intake thread and preserves a submitted report's review state. It remains an intake/thread-closure caller for Task 10. No new Discord review control or unused bot adapter was introduced. `ReportReview.unit.test.ts` uses the actual Discord context builder and compiled shared package to prove direct Discord-context reuse and provenance. The existing queued `open_case_from_observed_detection` worker execution remains with Task 3; this checkpoint adds its real encoding/decoding only, without an unused dispatch entry.
